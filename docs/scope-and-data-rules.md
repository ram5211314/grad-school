# 专业范围与数据口径

## 一期专业范围

- 0812 计算机科学与技术
- 0835 软件工程
- 0839 网络空间安全
- 0854 电子信息：计算机技术、人工智能、大数据技术与工程、软件工程等相关方向

## 必采字段

- 院校、学院、专业代码、专业名称、研究方向和培养方式
- 政治、英语一/二、数学一/二、408 或自命题专业课
- 年度招生计划、复试线、拟录取人数、报名人数（仅在官方公开时）
- 数据来源链接、适用年份、采集时间与审核状态

## 数据规则

- 以研招网和高校研究生院公开信息为准。
- 报名人数未公开时，报录比显示为“未公开”，不得估算。
- 不同年份数据必须分年度展示，推荐结果只作为择校辅助。
