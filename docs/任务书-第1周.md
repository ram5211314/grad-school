# 计算机专业考研择校平台 - 第1周任务书

## 1. 题目名称

**计算机专业考研择校平台**

## 2. 数据来源

### 2.1 数据来源
- **来源**：CPEER开源数据集（https://github.com/Younai2021/CPEER-Dataset）
- **采集方式**：从开源数据集下载并聚合
- **数据量**：649条结构化招生数据记录
- **覆盖范围**：
  - 高校数量：59所
  - 省份数量：15个
  - 年度范围：2020-2023年（4个年度）

### 2.2 数据字段
- 院校名称
- 学院名称
- 专业代码（0812计算机科学与技术、0835软件工程、0839网络空间安全、0854电子信息）
- 专业名称
- 研究方向
- 培养方式
- 政治科目要求
- 英语科目要求（英语一/英语二）
- 数学科目要求（数学一/数学二）
- 专业课要求（408统考或自命题）
- 年度招生计划（部分公开）
- 复试线（部分公开）
- 拟录取人数
- 报名人数（仅在官方公开时）
- 数据来源链接
- 适用年份
- 采集时间
- 审核状态

### 2.3 数据规则
- 以研招网和高校研究生院公开信息为准
- 报名人数未公开时，报录比显示为"未公开"，不得估算
- 不同年份数据必须分年度展示

## 3. 系统角色

### 3.1 管理员角色
**功能描述**：系统管理员，负责平台运营和数据管理

**主要功能**：
1. **数据管理**
   - 批量导入招生数据（CSV/Excel格式）
   - 数据格式校验和来源校验
   - 数据去重处理
   - 数据审核流程（待审核→已审核→已发布）
   - 数据发布管理

2. **用户管理**
   - 用户账号管理
   - 角色权限分配
   - 用户行为审计

3. **系统管理**
   - 系统配置管理
   - 操作日志查看
   - 错误报告处理
   - 数据备份与恢复

4. **运营管理**
   - 运营数据统计看板
   - 用户行为分析
   - 数据质量监控

### 3.2 普通用户角色
**功能描述**：已注册登录的考研学生，可使用全部功能

**主要功能**：
1. **学生画像**
   - 填写个人信息（本科专业、目标地区、成绩预估）
   - 设置院校层次偏好（985/211/双一流等）
   - 设置风险偏好（冲刺/稳妥/保底）

2. **院校检索**
   - 多条件筛选（省份、专业代码、科目类型等）
   - 关键词搜索
   - 分页浏览

3. **对比清单**
   - 最多5个院校专业对比
   - 保存在浏览器本地存储

4. **择校推荐**
   - 基于画像的个性化推荐
   - 冲刺/稳妥/保底分类
   - 推荐理由解释
   - 数学、408/自命题匹配分析

5. **收藏管理**
   - 收藏感兴趣的院校专业
   - 收藏列表管理

6. **备考计划**
   - 制定备考计划
   - 计划提醒功能

### 3.3 匿名用户角色
**功能描述**：未登录的访客，可使用基础功能

**主要功能**：
1. **浏览公开信息**
   - 查看院校列表
   - 查看专业列表
   - 查看基础招生信息

2. **基础检索**
   - 使用简单条件搜索
   - 查看搜索结果列表

3. **注册登录**
   - 注册新账号
   - 登录已有账号

## 4. 技术架构

### 4.1 前端技术
- **框架**：Vue 3
- **构建工具**：Vite
- **UI组件库**：Element Plus
- **路由**：Vue Router（Hash模式）
- **状态管理**：本地存储（localStorage）
- **HTTP客户端**：Axios

### 4.2 后端技术
- **业务服务**：Spring Boot + MyBatis-Plus
- **算法服务**：Flask + pandas + scikit-learn
- **API规范**：RESTful API
- **数据格式**：JSON

### 4.3 数据库技术
- **关系型数据库**：MySQL（生产环境）/ H2（开发环境）
- **缓存数据库**：Redis
- **数据分层**：
  - ODS层：原始数据存储
  - DWD层：清洗后数据
  - DWS层：汇总统计表
  - ADS层：应用数据表

### 4.4 大数据技术
- **离线计算**：Hadoop HDFS + Hive
  - HDFS：分布式文件存储
  - Hive：数据仓库查询
- **实时计算**：Apache Flink
  - 实时热度统计
  - 搜索热词分析
  - 数据增量同步

### 4.5 数据采集技术
- **采集方式**：Python脚本
- **采集策略**：
  - 只允许配置的官方域名
  - 抓取快照、SHA-256哈希、最终URL、采集时间
  - 不绕过访问控制
- **数据来源**：研招网、高校研究生院官网

### 4.6 部署技术
- **容器化**：Docker（可选）
- **Web服务器**：Nginx（可选）
- **版本控制**：Git
