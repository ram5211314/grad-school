# 计算机专业考研择校平台

面向计算机相关专业考研学生的院校专业检索、择校推荐和招生数据分析平台。

## 项目概述

本平台旨在帮助计算机相关专业考研学生进行科学择校，通过整合公开招生数据，提供个性化的院校推荐和决策支持。

### 题目名称
**计算机专业考研择校平台**

### 数据来源
- **来源**：CPEER开源数据集（https://github.com/Younai2021/CPEER-Dataset）
- **采集方式**：从开源数据集下载并聚合
- **数据量**：649条结构化招生数据记录
- **覆盖范围**：
  - 高校数量：59所
  - 省份数量：15个
  - 年度范围：2020-2023年（4个年度）

### 系统角色
1. **管理员**：数据管理、用户管理、系统管理、运营管理
2. **普通用户**：学生画像、院校检索、对比清单、择校推荐、收藏管理
3. **匿名用户**：浏览公开信息、基础检索、注册登录

## 一期 MVP 范围

- 学生画像：本科专业、目标地区、成绩预估、院校层次和风险偏好。
- 院校专业：覆盖 0812、0835、0839 与 0854 相关方向，包含历年招生计划、复试线、报录比、数学科目、408 或自命题专业课。
- 择校能力：条件筛选、多项目对比、收藏、冲刺/稳妥/保底推荐。
- 数据能力：HDFS/Hive 离线清洗与特征表，Flink 实时热度和数据更新指标。

## 技术架构

| 层级 | 技术 | 职责 |
| --- | --- | --- |
| 学生端/管理端 | Vue 3 + Vite + Element Plus | 查询、画像、推荐、数据维护 |
| 业务服务 | Spring Boot + MyBatis-Plus | 账号、权限、院校专业 CRUD、导入审核 |
| 在线存储 | MySQL + Redis | 业务主数据、缓存和会话 |
| 算法服务 | Flask + pandas/scikit-learn | 推荐评分、推荐解释、特征服务 |
| 离线数仓 | Hadoop HDFS + Hive | 历年招生数据存储、清洗、聚合与特征表 |
| 实时计算 | Flink | 数据增量同步、行为流、热门院校专业与搜索热词 |

## 当前运行

### 启动推荐服务

```powershell
cd services/recommendation
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

健康检查：`GET http://127.0.0.1:5001/health`

### 启动业务服务

```powershell
cd services/business-service
mvn spring-boot:run
```

业务服务：`http://127.0.0.1:8080`

### 启动前端

```powershell
cd web
npm install
npm run dev
```

前端访问：`http://127.0.0.1:5173`

## 数据规则

- 以研招网和高校研究生院公开信息为准
- 报名人数未公开时，报录比显示为"未公开"，不得估算
- 不同年份数据必须分年度展示
- 推荐结果只作为择校辅助，不构成录取承诺

## 注意事项

1. **数据真实性**：所有数据必须来自官方公开信息，不得估算或推测
2. **来源可追溯**：每条数据必须记录来源链接和采集时间
3. **审核流程**：数据必须经过审核才能发布
4. **隐私保护**：不收集用户敏感信息
5. **系统稳定性**：确保服务正常运行，数据不丢失
